# 💱 幣別與換算說明
<br>
當您涉及不同幣別之間的資產轉換時，本章節將說明正確的記帳處理方式。

---

## 1. 跨幣種轉換（不同幣別換匯）

當您將某個外幣帳戶的資金提領並兌換為另一種幣別（例如：外幣現鈔換台幣）時，系統建議使用 **「一筆支出 + 一筆收入」** 的雙向記錄方式：

<div class="p-4 my-4 rounded-2xl bg-amber-500/10 border border-amber-500/20 text-amber-900 dark:text-amber-200">
  💡 <strong>實例說明：</strong> 從中國銀行提取現金 RMB 10,000，在機場兌換成 TWD 45,500 並存入國泰世華台幣帳戶。
</div>

### 記帳操作步驟：

  <div class="p-3.5 rounded-xl bg-rose-500/10 border border-rose-500/20 flex items-center justify-between">
    <div class="flex items-center gap-2">
      <span class="px-2 py-0.5 rounded text-xs font-bold bg-rose-500 text-white">步驟 1</span>
      <span class="font-bold">中國銀行帳戶</span>
    </div>
    <span class="text-rose-600 dark:text-rose-400 font-bold">支出 10,000 RMB</span>

      <span class="font-bold">國泰世華帳戶</span>
    </div>
    <span class="text-emerald-600 dark:text-emerald-400 font-bold">收入 45,500 TWD</span>
  </div>
</div>

<div class="p-3 rounded-xl bg-base-200/60 text-xs opacity-75 border border-base-300 mt-4">
  📌 <strong>提示：</strong> 採用此方式能完美呈現各自帳戶的實際金額異動，同時確保資產總覽的匯率換算精準無誤。
</div>
