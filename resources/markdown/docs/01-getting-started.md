## ✏️ 快速開始記帳

請按照以下步驟完成您的第一筆記帳：

<div class="space-y-3 my-4">
  <div class="flex items-center gap-3 p-3 rounded-xl bg-base-200/40">
    <span class="w-7 h-7 rounded-full bg-teal-500 text-white font-bold flex items-center justify-center text-sm flex-none">1</span>
    <span>點擊畫面中央下方的 <strong class="text-teal-600 dark:text-teal-400">「+」鉛筆按鈕</strong>。</span>
  </div>
  <div class="flex items-center gap-3 p-3 rounded-xl bg-base-200/40">
    <span class="w-7 h-7 rounded-full bg-teal-500 text-white font-bold flex items-center justify-center text-sm flex-none">2</span>
    <span>選擇交易類型（<span class="text-rose-500 font-bold">支出</span> / <span class="text-emerald-500 font-bold">收入</span> / <span class="text-amber-500 font-bold">轉帳</span>）。</span>
  </div>
  <div class="flex items-center gap-3 p-3 rounded-xl bg-base-200/40">
    <span class="w-7 h-7 rounded-full bg-teal-500 text-white font-bold flex items-center justify-center text-sm flex-none">3</span>
    <span>輸入交易金額並選擇對應的收支類別。</span>
  </div>
  <div class="flex items-center gap-3 p-3 rounded-xl bg-base-200/40">
    <span class="w-7 h-7 rounded-full bg-teal-500 text-white font-bold flex items-center justify-center text-sm flex-none">4</span>
    <span>點擊 <strong class="text-teal-600 dark:text-teal-400">「確認儲存」</strong> 即可完成！</span>
  </div>
</div>
